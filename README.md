# linux-handheld-aarch64

Mainline Linux plus a handheld patch stack, built for **Arch Linux ARM
(aarch64)** and published as a signed pacman repository on Cloudflare R2.

Two packages come out of every build: `linux-handheld-aarch64` and
`linux-handheld-aarch64-headers`. Devices install them with `pacman -S`.

Target device today is the **AYN Odin 3** (Qualcomm Dragonwing CQ8725S /
SM8750).
